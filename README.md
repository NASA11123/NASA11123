**[php-tutorial](https://github.com/NASA11123/php-tutorial)** —— 一个双击就能打开学 PHP 的教学站

- 📚 **10 章 16 课**：从第一个 `echo` 一路讲到类与对象、文件操作、PDO 连数据库
- ✏️ **每节课里都嵌了能写能跑的代码框**：改两行 → 点「运行代码」→ 立刻看到结果，不用装本地环境
- 🧪 练习场 + 章节测验（自动判分、逐题讲解）+ 学习进度记录
- 📦 **零依赖**：自带 PHP 运行时，`./start.sh` 起站，不需要预先安装任何东西
- 🛡️ 在线执行有沙箱兜底：5 秒超时、64M 内存上限、禁掉 `shell_exec` / `system` 这类函数
